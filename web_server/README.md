
# Web Server

This directory contains my ALU System Engineering and DevOps web server project.

## Project Description

The project focuses on configuring and managing a web server using Bash scripts and Nginx.

## Tasks

### Task 0: Transfer a file to a server
**File:** `0-transfer_file`

A Bash script that transfers a file from the local machine to a remote server using SCP and SSH authentication.

### Task 1: Install Nginx web server
**File:** `1-install_nginx_web_server`

A Bash script that installs Nginx and configures it to serve content on port 80.

The web page displays:

`Holberton School for the win!`

### Task 2: Set up a domain name
Configure a free `.tech` domain to point to the web server's IP address using a DNS A record.

### Task 3: Redirection
**File:** `3-redirection`

A Bash script that configures Nginx to redirect requests from `/redirect_me` to a YouTube URL using HTTP status code 301.

### Task 4: Not found page 404
**File:** `4-not_found_page_404`

Configure Nginx to display a custom 404 error page.

### Task 5: Design a beautiful 404 page
**File:** `5-design_a_beautiful_404_page.html`

Create a custom HTML page for visitors who access a page that does not exist.

## Technologies Used

- Ubuntu Linux
- Bash scripting
- Nginx
- SSH
