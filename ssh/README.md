# ALU System Engineering & DevOps

## Project Description
This repository contains my work and practical exercises for the ALU System Engineering and DevOps program. It focuses on learning server administration, SSH configuration, authentication, and other DevOps concepts.

## Project: SSH

The `ssh` directory contains scripts and configuration files related to Secure Shell (SSH).

### Tasks Completed

**Task 0: Use a Private Key**
- Created a Bash script to connect to a remote server using an SSH private key.
- Used the `ubuntu` user for authentication.

**Task 1: Create an SSH Key Pair**
- Generated an RSA SSH key pair.
- Used a key size of 4096 bits.
- Set the passphrase to `betty`.
- Saved the private key as `school`.

**Task 2: Client Configuration File**
- Configured the SSH client to use the private key `~/.ssh/school`.
- Disabled password authentication.
